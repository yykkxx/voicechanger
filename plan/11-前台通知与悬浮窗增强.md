# 11-前台通知与悬浮窗增强

> 会话 #7 追加：通知增加多按钮 + 信息；新增前台悬浮窗。
> 会话 #8 追加：悬浮窗可缩小到右上角 + 点击恢复 + 快速切模式；通知/主界面可开关悬浮窗。
> 会话 #9 追加：点击悬浮窗外自动收起为胶囊；胶囊位置可拖动并记忆（下次收起停在上次位置）。

## 背景

用户反馈：
1. 当前通知只有"停止"按钮，缺少返听/静音/降噪等快捷控制；
2. 切后台后通知里看不到实时健康指标；
3. 希望有悬浮窗独立于 App 页面显示状态并快捷控制；
4. 悬浮窗要能缩小到右上角、点击恢复、快速切换模式；
5. 前台通知与主界面都能开关悬浮窗。

## 设计

### 通知增强（buildNotification）
- 标题：Voice Changer
- 内容：当前状态文本（模式 + flags）
- 点击内容区：打开 MainActivity
- 停止按钮：ACTION_STOP
- 返听按钮（当 session running）：ACTION_TOGGLE_MONITOR
- 静音按钮：ACTION_TOGGLE_MUTE
- 降噪按钮：ACTION_TOGGLE_NOISE
- 悬浮窗按钮：ACTION_TOGGLE_OVERLAY（开/关悬浮窗，文字随状态变化）
- 共 5 个快捷按钮，通过 PendingIntent 触发

### 悬浮窗（OverlayController）
- TYPE_APPLICATION_OVERLAY（Android 10+）/ TYPE_PHONE（更低版本）
- FLAG_NOT_FOCUSABLE + FLAG_NOT_TOUCH_MODAL，不影响其他应用交互
- 初始位置：左上角 (12dp, 160dp)
- 完整面板：状态/模式/flags/健康指标 + 两行按钮
  - 第一行：返听 / 静音 / 降噪
  - 第二行：模式⇄（快速循环切换）/ 缩小 / 停止
- **缩小态**：右上角小胶囊（"VC 模式●"），点击胶囊恢复完整面板
  - 缩小后吸附到屏幕右上角（container.post 按实际胶囊宽度贴边）
  - 恢复时回到缩小前位置
- 拖动：整窗可拖（完整态与胶囊态均可）
- **所有 WindowManager/View 操作统一主线程 Handler**（show/update/dismiss/minimize/expand）

### 服务集成（VoiceChangerService）
- 新增 ACTION_CYCLE_MODE（循环切换：PASSTHROUGH → INTERNAL → LOOPBACK_SOCKET → MUTE → ...）
- 新增 ACTION_TOGGLE_OVERLAY（通知按钮；toggleOverlay()）
- 新增 `_overlayVisible` StateFlow（悬浮窗总开关，默认 true）
- startInternal 成功后调用 showOverlay()（showOverlay 内部检查 _overlayVisible）
- stopInternal 里调用 hideOverlay()
- metrics 循环每 500ms 调用 overlay.update(...)
- setNoiseInternal 同步更新 `_noiseEnabled` 并 updateNotification
- 公共接口 setOverlayVisible(visible)（主界面开关调用，applyOverlayVisible 实现）

### 主界面（MainScreen/MainActivity）
- 新增"悬浮窗"开关行（Switch 绑定 overlayVisible）
- onOverlayToggle 回调 → service.setOverlayVisible

### 权限
- Manifest 声明 SYSTEM_ALERT_WINDOW（通过 priv-app 部署自动授权）
- Android 10+ overlay 类型用 TYPE_APPLICATION_OVERLAY

## 根因/风险
- `canShow()` 未通过时 show() 为 no-op，日志 warn；不影响功能
- **悬浮窗必须经主线程更新 UI**（Android View 线程限制）；
  初次实现时 overlay.update() 在协程线程直接调用 setText，导致
  `CalledFromWrongThreadException` 崩溃。修复：show/update/dismiss
  均通过 `mainHandler.post { ... }` 切换到主线程。
- 缩小到右上角用 container.post 延迟取胶囊实际宽度贴边，
  避免 View 未布局时宽度为 0。
- overlay 使用 PendingIntent.getService，服务无需持有 overlay 实例
- 通知按钮同样通过 PendingIntent，支持锁屏与锁屏后操作

## 验证（真机 logcat）
- `VC/Overlay: overlay shown` / `minimized to corner` / `expanded` ✓
- `VC/Service: overlayVisible=false` + `overlay dismissed`（关悬浮窗）✓
- `overlayVisible=true` + `overlay shown`（开悬浮窗）✓
- 会话健康：`cap/proc/under/drop/rms` 持续正常，无崩溃 ✓
